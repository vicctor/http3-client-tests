1995 SSL 2.0 First public version; insecure 🚫 Deprecated

🌐 History of HTTP: The Evolution Journey

Year Version Key Features & Improvements Status
1996 HTTP/1.0 Basic request-response, simple and inefficient 🚫 Deprecated
1997 HTTP/1.1 Keep-alive connections, pipelining support 📉 Legacy
2012 Google QUIC First experiments with QUIC protocol 🔬 Experimental
2015 HTTP/2 Multiplexing over TCP, server push ✅ Widely Used
2015 QUIC IETF QUIC standardization process begins 📋 Standardization

 RTT Cost:
 ─────────
 • HTTP/2 (TLS 1.2): TCP (1 RTT) + TLS (1 RTT) = ~2 RTT before request
 • HTTP/2 (TLS 1.3): TCP (1 RTT) + TLS (0.5 RTT) = ~1.5 RTT
 • HTTP/3 (QUIC): Combined handshake = 1 RTT (first time), 0 RTT (resumed)

🚦 Multiplexing

HTTP/2 (TCP)

  • Head-of-line blocking
  • Single TCP stream
  • Packet loss affects all streams

HTTP/3 (QUIC/UDP)

  • Independent streams
  • Per-stream flow control
  • Packet loss affects only one stream

🗜️ QPACK (RFC 9204)

Header compression for HTTP/3

QPACK vs HPACK

HPACK (HTTP/2)

  • Head-of-line blocking in headers
  • Sequential updates required
  • Single compression context

QPACK (HTTP/3)

  • Separate streams for table updates
  • Headers can flow independently
  • Dynamic table on separate stream

📊 Static vs Dynamic Tables

  • Static Table: Fixed common headers (`:method: GET`, `:scheme: https`)
  • Dynamic Table: Runtime custom headers
    • Cookie values
    • Authorization tokens
    • Custom headers

⚖️ Production Trade-offs

✅ HTTP/3 Dominates

  • High latency (>50ms RTT)
  • Packet loss (>1%)
  • Mobile networks (4G/5G)
  • Network switching (WiFi ↔ LTE)
  • Frequent reconnections (0-RTT)

⚖️ HTTP/2 Still Competitive

  • Perfect conditions (<10ms RTT, 0% loss)
  • Very small transfers (<10KB)
  • Legacy systems (limited CPU/RAM)
  • Network restrictions (UDP 443 blocked)

🏆 Golden Rules

Use HTTP/3 when:

  • High RTT (>50ms)
  • Packet loss (>1%)
  • Mobile networks
  • Network switching during sessions
  • Frequent reconnections

Stick with HTTP/2 when:

  • Perfect conditions (<10ms RTT, 0% loss)
  • Very small transfers
  • Resource-constrained devices
  • UDP 443 blocked
